First-run setup

Riley Studio runs everything on this machine. Three one-time steps:
  1. Core tools — 
    powershell -ExecutionPolicy Bypass -File riley-studio\setup_studio.ps1
  2. AI backend (ComfyUI + quant loaders) — 
    ... setup_studio.ps1 -Ai        (NVIDIA GPU)
... setup_studio.ps1 -Ai -CpuOnly
  3. Model weights — open the Models window and pull a tier. Start with sd15.
