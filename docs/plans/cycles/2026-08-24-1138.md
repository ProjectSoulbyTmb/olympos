## Decisions & rationale

1. **Architecture:** Python-stdlib threaded HTTP server + single-file SPA.
   Video requirement rules out tkinter (no playback); Electron/WPF rejected
   as dependency-heavy against local-first doctrine. Browser engine supplies
   codecs; server supplies confinement + range streaming.
2. **Content-blind by explicit operator instruction** — no subject-matter
   filtering anywhere. Containment features kept (loopback bind, GET/HEAD
   only, realpath one-root confinement, hidden-dot exclusion): these protect
   privacy, they do not police content.
3. **Registry row NOT applied** despite fleet convention — operator's
   "not connected to any other trees" constraint outranks registration;
   sentinel gating would couple APHRODITE to the fleet. Ready-to-paste v2 row
   preserved in `aphrodite/README.md` for a future logged reversal.
4. `verify_aphrodite.py` at repo root per house gate convention
   (`verify_forseti.py` style).
